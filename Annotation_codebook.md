# Codebook ручной разметки MMoRWaD

**Задача:** Детекция бытовых отходов с определением материала.

**Исходный датасет:** MMoRWaD — Multi Modal Recyclable Waste Management Dataset.

**Тип разметки:** Bounding boxes и категориальные характеристики объектов.


## 1. Общие принципы

Для каждого целевого предмета необходимо:
1. Присвоить метку класса материала на основании заранее подготовленного справочника предметов.
2. Построить ограничивающий прямоугольник (bounding box).
3. Указать дополнительные характеристики объекта в соответствии с правилами разметки.
4. Зафиксировать неоднозначные случаи для дальнейшего обсуждения.

## 2. Классы материалов

В качестве меток используются 18 исходных классов MMoRWaD.

| Класс | Описание |
|---|---|
| PET | Полиэтилентерефталат |
| HDPE | Полиэтилен высокой плотности |
| LDPE | Полиэтилен низкой плотности |
| PP | Полипропилен |
| PS | Полистирол |
| PVC | Поливинилхлорид |
| Other | Прочий пластик |
| ALU | Алюминий |
| FE | Сталь |
| Clear Glass (GL) | Прозрачное стекло |
| Brown Glass (GL) | Коричневое стекло |
| Green Glass (GL) | Зелёное стекло |
| Paper (PAP) | Бумага |
| Paperboard (PAP) | Тонкий упаковочный картон |
| Cardboard (PAP) | Картон |
| Paper + Plastic (C/PAP) | Композит бумаги/картона и пластика |
| Paper + Plastic + Al (C/PAP) | Композит бумаги/картона, пластика и алюминия |
| Plastic + Al (C/PE) | Композит пластика и алюминия |

Класс материала назначается на основании заранее подготовленных метаданных о предмете, полученных при изучении маркировки упаковки. Аннотаторы не определяют химический состав материала по внешнему виду изображения, а используют согласованный справочник соответствия маркировок классам MMoRWaD. При неоднозначной маркировке предмет направляется на дополнительную проверку. В метаданных название материала сокращено для удобства. В разметке используем класс из таблицы выше

Внешний вид предмета сам по себе не считается достаточным основанием для точного определения полимера.

Если материал не удаётся установить достоверно, он фиксируется как неопределённый для последующего обсуждения. Использовать класс Other для любых неизвестных материалов запрещается: он относится только к пластику.

## 3. Правила построения bounding boxes

1. Bounding box должен охватывать весь видимый целевой предмет.
2. Рамка строится максимально близко к внешним границам предмета.
3. Не допускается намеренное включение лишнего пространства вокруг объекта.
4. Тени предмета не включаются в рамку.
5. При наличии крышки, прикреплённой к бутылке или контейнеру, она включается в общую рамку.
6. Этикетка, расположенная на упаковке, входит в рамку основного предмета.
7. Для смятых и деформированных объектов рамка строится по фактическим внешним границам.
8. При изменении положения предмета рамка должна соответствовать его текущей ориентации.
9. Части объекта, находящиеся вне кадра, не дорисовываются.

Формат координат для экспорта в COCO: `[x, y, width, height]`, где `x` и `y` — координаты левого верхнего угла рамки.

## 4. Дополнительные характеристики

Для совместимости с исходным датасетом используются следующие признаки.

| Признак | Возможные значения | Описание |
|---|---|---|
| Hue | Значения исходного MMoRWaD | Визуальный цвет предмета |
| Top/Cap | Yes / No-N/a | Наличие крышки |
| Label | Yes / No-N/a | Наличие этикетки |
| Contaminates | Yes / No-N/a | Наличие видимых загрязнений |
| Deformation | Yes / No-N/a | Наличие деформации |

`No-N/a` используется как при отсутствии признака, так и при его неприменимости, в соответствии с исходной системой обозначений.

Если нельзя выделить преобаладющий цвет используем Other.

Если по фото не поределеяется наличие крышки или этикетки и тд, то ставится No-N/a

Этикеткой считается только отдельно наклееная этикетка, то есть если текст нанесен на саму упаковку и его нельзя снять, то ставить No-N/a
## 5. Особые случаи

**Бутылка с содержимым.** Класс материала назначается по материалу корпуса бутылки, установленному при подготовке метаданных. Наличие жидкости внутри не изменяет класс материала. Например, прозрачная PET-бутылка с молоком относится к классу PET.

**Бутылка без крышки.** Класс материала корпуса не меняется, признак Top/Cap принимает значение No-N/a.

**Предмет со снятой этикеткой.** Класс материала не меняется, признак Label принимает значение No-N/a.

**Смятая упаковка.** Материал сохраняется, а деформация фиксируется отдельным признаком. Bounding box строится по изменённой форме.

**Отдельная крышка.** Рассматривается как самостоятельный предмет, если присутствует на отдельной фотографии. Материал определяется по маркировке или подтверждённому составу.

## 6. Проверка согласованности

После завершения проводится сравнение:

- совпадения присвоенных классов;
- совпадения дополнительных признаков;
- пространственного совпадения bounding boxes с помощью IoU.

Поскольку классы материалов назначаются на основании общего справочника, основное внимание при оценке независимой разметки уделяется геометрической согласованности и дополнительным характеристикам объектов.

Все разногласия фиксируются и обсуждаются. После согласования создаётся итоговая версия аннотаций.

## 7. Хранение результатов

Для каждого изображения сохраняются:

- уникальный идентификатор изображения;
- имя файла;
- размеры изображения;
- класс материала;
- координаты bounding box;
- дополнительные характеристики;
- идентификатор аннотатора в независимой версии разметки;
- отметка о спорных случаях.

Итоговая разметка экспортируется в совместимый с обучением стандартный формат COCO.

Оригинальные фотографии сохраняются без изменения разрешения и соотношения сторон.


## Спорные случаи
1. В исходном датасете отсутсвует материал C/LDPE, так что нужно сопоставить с имеющимися композитными материалами.
- если указан код 4 в метаданных, то это "LDPE"
- если указан код 90, то это "Plastic + Al (C/PE)", также сюда идет 90 C/ALU
- если не указан код, ориентируемся на внешний вид и сторонние источники. 
Так для упаковки кетчупа используем "Plastic + Al (C/PE)". Для маски Tashe также будем использовать "Plastic + Al (C/PE)" по схожему с кетчупом материалу на вид и наощупь.
2. Пакетик чая имеет материал C/PP, то есть тоже композит. Опираясь на внешний вид это будет "Paper + Plastic + Al (C/PAP)"
3. Крем Faberlic также имеет на упаковке LDPE/HDPE. Опираясь на схожий материал крема Geltek можно предположить, что основная упаковка LDPE, HDPE - материал крышки, поэтому выбираем LDPE
4. Для бумажных и картонных изделий используются следующие правила сопоставления:
- 20 PAP -> Cardboard (PAP) — гофрированный картон.
- 21 PAP -> Paperboard (PAP) — негофрированный упаковочный картон.
- 22 PAP -> Paper (PAP) — бумага.
5. Для стекла:
- 70 GL -> Clear Glass (GL)
- 71 GL -> Green Glass (GL)
- 72 GL -> Brown Glass (GL)
